 About Me 
I’m a cybersecurity engineer driven by a simple idea: to defend a system well, you first have to understand how it breaks. 
My work sits at the intersection of offensive and defensive security — I value the adversarial mindset of Capture The Flag
competitions, the discipline of building resilient infrastructure, and the leverage that comes from automating security at scale. 
I live in the terminal, script relentlessly, and treat every new tool, exploit class, and cloud primitive as something worth
understanding deeply. Security isn’t a checklist to me; it’s a craft I practice every day. 
Focused on security engineering, threat analysis, and secure automation
Active CTF player — web, forensics, reversing, and privilege escalation
Linux power user, genuinely at home on the command line
Exploring the security of cloud-native and AI-driven systems
Committed to continuous learning and hands-on research
